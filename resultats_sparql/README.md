# Résultats des Requêtes SPARQL

Ce dossier contient les résultats des requêtes SPARQL exécutées sur le graphe RDF des accidents routiers.

## Fichiers de résultats

- `accidents_par_departement.csv` - Accidents classés par nombre d'usagers impliqués
- `donnees_pietons.csv` - Données spécifiques aux piétons
- `dbpedia_departements.csv` - Départements avec données DBpedia (population, superficie)
- `accidents_mortels_meteo.csv` - Accidents mortels selon conditions météorologiques
- `types_vehicules.csv` - Répartition des véhicules impliqués
- `accidents_luminosite.csv` - Accidents selon conditions de luminosité
- `accidents_voies_reservees.csv` - Accidents sur pistes cyclables et voies réservées
- `profil_victimes.csv` - Profil démographique des victimes
- `pietons_localisation.csv` - Localisation et actions des piétons
